项目概述

GeoGR²（Geospatial Graph Refine Reasoning）是一个基于图消息传递机制的零样本地理空间推理 Agent 框架，针对大语言模型（LLM）在地理空间预测任务中的两大核心缺陷——空间孤立性（每个地点被当作独立个体预测，违背"地理学第一定律"）与区域分布偏见（训练语料偏向发达/人口稠密地区，导致欠发达地区预测失真），设计了一套无需任何模型微调的推理阶段解决方案。

框架将传统的"孤立点预测"转变为"图上的协同推理"过程：在推理阶段动态构建邻居图，引入真实地理数据作为"物理锚点"，通过多轮迭代修正机制（Refine Reasoning）强制模型满足地理空间一致性约束。

💡 核心洞察：地理学第一定律——"空间上相近的事物关联度更高"。GeoGR² 让 LLM 像 GNN 一样在动态图上进行消息传递，但无需任何训练数据或微调，纯推理阶段实现。

三大核心算子

T Topology 拓扑算子
解决"谁是参考对象"——为每个目标点动态构建邻居集合。
物理近邻：全局10个欧氏最近邻（确定性）
语义类比：5°×5°区域内LLM选5个语义相似点（自适应）
F Feature 特征算子
解决"用哪些背景信息"——LLM根据任务自主筛选协变量。
支持 WorldClim BIO1-BIO19 共19个生物气候变量，如年均温(BIO1)、年降水量(BIO12)等。
U Update 更新算子
解决"如何综合修正"——LLM担任空间协调员执行消息传递。
综合目标点与参考点的特征/数值偏差，区域生物气候模式，输出科学修正值。

Refine Reasoning 多轮迭代机制

系统设计了 K 轮（K < N，N 为总点数）迭代修正闭环，每轮都使用上一轮修正后的预测值重新选点，实现"迭代反思"。

初始CSV (stage0) │ ▼ ┌────────────────────────────────────────────────┐ │ 第 1 轮 (生成 stage1) │ │ 对每个点： │ │ 1. 辅助变量选择 → 变量列表 │ │ 2. 参考点选择 → 相似点索引 │ │ 3. 修正 Agent → 新预测值 │ │ 4. 更新缓存 & 新 DataFrame │ │ 计算 Spearman/Bias → 记录到指标文件 │ └────────────────────────────────────────────────┘ │ (若 Spearman 提升/持平) ▼ ┌────────────────────────────────────────────────┐ │ 第 2 轮 (生成 stage2) │ │ 相同流程，但参考点数据来自 stage1 的修正后预测值 │ │ → 实现"迭代反思"，图上的消息逐级传播 │ └────────────────────────────────────────────────┘ │ (直到 Spearman 严格下降或达到 max_rounds) ▼ 停止迭代，输出最佳阶段 CSV
⚠️ 动态停止策略：仅当 Spearman 相关系数严格下降时停止迭代。若持平或上升则继续（直到 max_rounds），避免过度修正导致的性能退化。

模块化多 Agent 架构

系统由四个解耦的 Agent 协作完成，每个 Agent 独立可测试、可替换：

AuxVariableSelector 辅助变量选择（Feature 算子）
PointSelector 参考点选择（Topology 算子）
PredictionRefiner 预测修正（Update 算子）
RefinementEvaluator 效果评估（预留接口）

项目亮点

🔬 零样本 & 免训练的图推理能力

不修改 LLM 内部任何参数，纯靠推理阶段的机制设计实现类似 GNN 的空间消息传递能力：

  • 无需标注数据：不需要任何训练集，零样本即插即用
  • 模型无关：支持 GPT-4、Gemini、Together 等任意 LLM 后端
  • 即插即用：更换任务/模型只需修改参数，无需重新训练

🔗 动态图结构（突破 GNN 静态拓扑限制）

传统 GNN 需要预定义固定的图拓扑结构，而 GeoGR² 在推理时动态寻找"上下文邻居"：

  • 每个目标点的邻居图独立构建
  • 每轮迭代使用上一轮修正后的预测值重新选点（迭代反思）
  • 打破静态网格限制，适应不同地理尺度

⚖️ 显著缓解地理偏见

通过强制模型参考周边真实数据（空间一致性检查），大幅降低 LLM 对欠发达地区的系统性预测偏见，提升预测公平性。

🔄 工程化设计

  • RefinementCache 缓存机制：记录每轮每个点的修正状态（pending/completed/failed），支持中断后无缝续传
  • 并发处理：ThreadPoolExecutor 支持多线程加速
  • API 速率控制：内置请求间隔，避免限流
  • 完整指标追踪：每轮自动计算并记录 Spearman 和 Bias 变化

混合选点机制

类型数量选择范围依据特点
最近邻点 10 全局 空间欧氏距离（经纬度） 确定性，保证局部连续性

设计理念：选点逻辑 = 空间最近邻（确定性）+ LLM 语义选点（自适应），兼顾地理定律的可靠性与LLM的知识灵活性，为修正器提供高质量参考点集合。

工程化设计

  • 两阶段解耦：GeoLLM 初始预测与 GeoGRR 图推理修正完全分离，可独立运行
  • 断点续传：RefinementCache 记录每轮每个点状态，中断后无缝恢复
  • 多线程并发：ThreadPoolExecutor 加速批量处理，内置API速率控制
  • 栅格数据支持：rasterio 读取 GeoTIFF，支持 WorldClim 生物气候变量
  • 地图可视化：folium 生成交互式 HTML 地图，直观展示预测结果
  • 完整评估体系：Spearman 等级相关 + Bias 分数双指标自动追踪
  • 模块化架构：4个Agent完全解耦，符合软件工程最佳实践，易于扩展
  • 跨平台兼容：支持 Linux / macOS，提供 DEPLOYMENT.md 部署指南
