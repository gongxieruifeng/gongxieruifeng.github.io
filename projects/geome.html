项目概述

GeoME 是一个零训练、多轮对抗性溯因推理智能体框架，针对大规模视觉语言模型（LVLMs）在地理定位任务中的"先验主导"幻觉问题，通过模拟人类"System 2"慢思考的多阶段辩论机制，将视觉地理定位从"模式匹配"重构为"证据链驱动的深度推理"。

现有 LVLMs（如 GPT-4o、Gemini、Qwen-VL）看到红色电话亭就判定为"英国"，即使图像实际拍摄于仿英式主题街区——这种视觉歧义导致模型在反直觉场景中频繁误判。GeoME 通过纯 Prompt 编排，无需任何微调即可让通用 LVLM 突破这一瓶颈。

💡 核心洞察：地理定位的瓶颈不在于模型"能看到什么"，而在于"能推理多深"。GeoME 证明：通过 Prompt 级别的辩论编排，通用 LVLM 无需微调即可展现出强大的空间推理能力，甚至超越领域专用微调模型。

四阶段闭环架构：Candidate-Debate-Judge-Reflect

GeoME 的核心创新是模拟人类 System 2 慢思考的四阶段闭环推理流程，完全自包含、不依赖外部地图 API、不修改模型权重。

核心创新机制

🎭 魔鬼代言人机制（Devil's Advocate）

在辩论阶段，模型被强制扮演"魔鬼代言人"角色，主动寻找双向证据——这是证伪式推理的核心，也是 System 2 思维的关键特征：

✅ 支持证据 E+
哪些视觉线索支持这个候选国家？（如：路牌文字、建筑风格、植被类型）
❌ 反驳证据 E-
哪些视觉线索反驳这个候选国家？（如：车牌格式不符、气候植被矛盾）

模型不再单方向寻找支持理由，而是被迫进行证伪，有效解决视觉歧义问题。

📊 信念熵驱动的元推理（Belief Entropy）

信念熵 H(C_t) 是 GeoME 的关键不确定性度量指标，量化模型在辩论各轮次中信念分布的演化：

  • 初始高熵 → 模型对多个候选犹豫不决
  • 熵持续下降 → 辩论逻辑在有效收敛信念、降低认知噪声
  • 当熵稳定在阈值之上 → 反思 Agent 介入，重构候选空间
实验验证：在 Gemini-3 + OSV-5M 上，初始熵 0.8360 → 最终熵 0.4555，降幅 45.5%。正确预测的最终熵始终低于错误预测，证明熵是推理质量的有效代理指标。

🚫 特征规避机制（Feature Evasion）

这是 GeoME 的核心差异化创新，专门针对"先验主导"问题设计：

  • 动态识别：自动识别在多个候选中反复出现的高频特征（如通用城市天际线、红色电话亭等统计相关但非地域唯一的特征）
  • 主动抑制：将这些误导特征标记入抑制集 F_t^-，在后续推理中排除
  • 长尾证据挖掘：强制模型回答"除了这些常见特征，还有什么细节支持/反驳这个结论？"，推动模型挖掘具有地域唯一性的长尾证据
效果：模型从统计相关性（"红色电话亭 → 英国"）转向深度逻辑推理（"路牌字体样式 + 植被类型 + 气候特征 → 英国南部"）。

⚡ 信心驱动的自适应路由

Candidate Agent 首先评估预测信心，平衡效率与精度：

  • 高信心 → 直接输出结果，跳过辩论（高效模式）
  • 中/低信心 → 生成 Top-5 候选并进入辩论循环

只有歧义场景才承担多轮推理的成本，简单场景快速通过。

  • 200 个反直觉难定位样本（如亚洲街景模仿欧洲风格）
  • 专门用于压测智能体穿透视觉误导的能力
  • 验证了 Feature Evasion 机制在极端歧义场景下的有效性

工程化设计

  • 零训练、零样本：直接接入现成 LVLM（GPT-4o/5、Gemini-3、Qwen2.5-VL/Qwen3-VL），无需微调，即插即用
  • 异步高吞吐：基于 AsyncOpenAI 实现并行推理，支持批量处理
  • 断点续跑：每 N 张图片自动保存结果 CSV，支持从中断处恢复
  • 离线坐标查询：内置约 200 个国家的静态坐标字典，Haversine 误差计算完全离线
  • 跨平台兼容：支持 Linux / macOS / Windows（含 Windows 事件循环特殊处理）
  • 可复现性保障：固定随机种子（默认 seed=666）、结果 CSV 包含完整推理轨迹（初始/最终熵、证据链、辩论轮数）
  • 可解释性：每条预测都附带 E+/E- 双向证据链，推理过程完全透明可审计
