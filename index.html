CompileLight —— 轻量级智能编译守卫 Agent
KN Group · 算法实习生

项目描述：针对企业客服 Agent在高频任务中重复检索、推理与执行不可审计的痛点，设计 "Trace-Registry-Retrieval-Control-Execution" 闭环，对已知子目标优先复用资产，对未知缺口触发有界推理，降低推理开销并提升执行可控性。

  • 控制与编译：提出 "LLM 提议、代码批准" 原则，构建 Normalize-硬过滤-混合召回-SAD-Blueprint-确定性编译 流水线，采用 PostgreSQL FTS + pgvector 多路召回与 RRF 融合；引入语义缓存（Hot Cache）对相似意图复用历史 Blueprint，命中率达 68%，命中请求 P95 由 8.7s 降至 580ms；通过 编译门禁（Schema / 权限 / 风险 / 预算）约束模型提议，对其执行确定性校验。
  • 执行与路由：基于 LangGraph 实现确定性 Meta-Executor，支持 REUSE / HYBRID / NEW 三模式路由、自动重试 / 补偿与人工 Checkpoint 恢复；NEW 模式在低置信度时切换受控探索策略——在受控白名单内深度探索，受控推理引擎按"冻结上下文-缺口分类-有限推理-输出验证"流程执行，配合 预算门禁 防止无限循环与越权调用。
  • 资产工程：将成功 Trace 异步沉淀为可复用资产，设计 Header 召回 + Contract 匹配两级索引与 DRAFT-ACTIVE 生命周期，沉淀 5 类 Kind（Tool/FSM/DAEF/Adapter/Validator），支持检索一跳扩展与执行视图冻结，避免执行中版本漂移。
  • 量化结果：在 10,284 次真实流量回放中，综合成功率达 89.4%，全任务端到端 P95 为 54.2s，较 ReAct 基线节省 74.8% Token；经审计无越权调用与重复副作用，编译门禁全通过，形成可回放、可审计、可持续资产抽取闭环。
GeoME —— 多阶段辩论与特征规避的视觉地理溯因推理框架
项目负责人 · 一作 在投

项目描述：针对大规模视觉语言模型（LVLMs）在地理定位中的"先验主导"幻觉问题，设计零训练多轮溯因推理框架，以候选假设的对抗验证与动态特征规避抑制误导性视觉先验。

  • 架构设计：提出了 "Candidate-Debate-Judge-Reflect" 的四阶段闭环架构，将视觉匹配重构为证据链驱动的溯因推理。通过"恶魔代言人"机制，引导模型主动寻找支持与反驳的双向证据（E⁺/E⁻），缓解视觉歧义与早期先验锚定。
  • 反思与候选更新：在辩论阶段引入 信念熵（Belief Entropy）作为不确定性度量，驱动模型进行元推理（Reflection）。通过动态剔除弱证据假设、重新进行采样，降低 Agent 在歧义场景中陷入局部最优的风险。
  • 特征规避机制：设计了动态特征规避机制（Feature Evasion），自动识别并抑制误导性高频特征，推动模型挖掘具有高地域判别性的"长尾证据"，实现候选空间的迭代修正。
  • 量化结果：在 IM2GPS3K 测试中，框架与基础 LVLM 结合达 94.19% 准确率，提升 10%–15%，Haversine 误差降低 68.1%。同时，自建 GeoReplica-200 测试集验证了框架在复杂视觉歧义环境中的鲁棒性。
GeoGR² —— 图推理驱动的零样本地理空间预测框架
项目负责人 EMNLP 已录用

项目描述：针对 LLM 在 GDP、温度、降水等地理空间预测中的空间孤立与区域分布偏差，设计无需微调、基于图结构协同推理的自主推理框架，通过真实观测数据 Grounding 与邻域协同推理提升预测一致性。

  • 架构设计：构建 "Topology-Feature-Update" 三阶段循环工作流，通过 物理近邻+语义类比双重拓扑算子引入真实数据作为"物理锚点"，并利用 Feature 算子驱动 LLM 自主筛选任务相关协变量，将孤立点预测转变为图上的协同推理。
  • 迭代推理：设计 Refine Reasoning 闭环，由 LLM 担任空间协调员，通过对比目标点与邻域节点的特征/数值偏差，进行多轮（K<N）迭代修正，强制模型满足地理空间一致性约束，显著缓解长尾数据预测偏见。
  • 量化结果：在 GDP、温度、降水等预测任务中，Spearman ρ 最高提升 67.9%，区域 Bias 最高降低 87.5%，显著缓解长尾地区的预测偏差。

FGFormer —— 相位感知时空预测 Transformer
项目负责人 在投

项目描述：针对时空 Transformer 主要依赖内容相似度、难以区分外观相似但运动趋势相反序列的问题，提出 FGFormer；基于傅里叶移位定理将相位信息显式注入时间注意力，并结合帧间差分表征增强动态模式建模。

  • 相位感知时间注意力（Phase-RoPE）：基于傅里叶移位定理，对 Q/K 施加随时间步递进的相位旋转，使注意力同时建模内容相关性与相对相位差，抑制运动方向不一致帧间的错误关联；支持自由频率与速度耦合两种模式，后者通过 θ=ωv 显式编码运动速度，每层仅引入 8 个可学习参数。
  • 时间差分表征（Diff Embedding）：构建独立差分分支，将 Δxt=xt-xt-1 与原始帧分别映射后融合，在输入端显式编码局部变化趋势，实现静态内容与动态信息解耦，增强模型对短期运动变化的感知能力。
  • 时空建模骨干：构建 Space→Time→Space 三阶段 Gated Transformer，分别建模帧内空间关系与跨帧时间依赖，并结合 SwiGLU、残差连接完成多层时空交互，在保持轻量化的同时强化长期动态建模。
  • 量化结果：MMNIST 上 MSE 23.00、SSIM 0.9483，较纯 Transformer 基线（MSE 35.13）降低 34.5%；TaxiBJ 上以 2.5M 参数 / 0.62G FLOPs 达到 PredFormer-d256（6.4M / 1.66G）同等精度，参数量与计算量降低 61% 与 63%。
